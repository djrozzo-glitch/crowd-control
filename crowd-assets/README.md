# Crowd Control — asset pack

12 transparent PNG sprites: four characters and eight festival objects.
All sprites use the same 362 × 362 canvas and originate from the included atlas.
Characters face toward the bottom of the image. Rotate around the sprite center for other directions.
These are static illustrations, not animated frames. Scale independently when drawing in game.
The environment objects use a slightly angled top-down perspective.

The favicon is derived from the security guard. The atlas and separate sprites are supplied.
Suggested game rendering: characters 24–36 px, stage 160–220 px; adjust to fit.
